## วิธีใช้หลักสูตรนี้

```bash
# Clone repository
git clone <repo-url>
cd bash_shell_course

# อ่าน Part ตามลำดับ
cat part-01-introduction.md

# รัน script ตัวอย่าง
chmod +x scripts/*.sh
./scripts/example.sh
```

## ข้อกำหนดเบื้องต้น
- Linux/macOS system (หรือ WSL บน Windows)
- Terminal emulator
- bash version 4.0+ (`bash --version`)
- root/sudo access (สำหรับ Part สูง)
